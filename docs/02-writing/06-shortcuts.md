# Keyboard shortcuts

In the app: the main menu's **Help** (or `Ctrl+/`, or `F1`) → **Keyboard shortcuts**. On macOS read Ctrl as Cmd where the system uses it.

## Windows and tabs

| Keys | What it does |
|---|---|
| `Ctrl+N` | New page |
| `Ctrl+Shift+N` | New window |
| `Ctrl+O` | Open a folder |
| `Ctrl+T` | New tab (a copy of this one) |
| `Ctrl+W` | Close the tab |
| `Ctrl+Tab / Ctrl+Shift+Tab` | Next / previous tab, in tab order |
| `Ctrl+PageDown / Ctrl+PageUp` | Next / previous tab, in tab order |
| `Alt+W` | Switch to the tab you used before this one; keep Alt down and press W again to go further back (Shift+Alt+W goes the other way) |
| `Alt+Left / Alt+Right` | Back / forward in this tab |
| `Ctrl+,` | Preferences |
| `Ctrl+/` | This list of shortcuts |
| `F1` | Help (documentation, shortcuts, logs, about) |

## Moving around

| Keys | What it does |
|---|---|
| `F6` | Move the keyboard between the page tree and the editor |
| `F9 / Shift+F9` | Show or hide the page sidebar / the outline sidebar |
| `Ctrl+Shift+F` | Search all pages |
| `F2` | Rename the open page (in the tree: the selected one) |

## Page tree

| Keys | What it does |
|---|---|
| `Up / Down` | Select the previous / next page (and open it) |
| `Right` | Expand, or go to the first sub-page |
| `Left` | Collapse, or go to the parent |
| `Home / End` | Select the first / last page |
| `Enter` | Move to the editor |
| `F2` | Rename the page |
| `Delete` | Delete the page (asks first) |
| `Any letter` | Open the tree's find box with that letter: matching pages light up, Up / Down move between them without opening, Enter opens the current one, Esc closes the box |

## Editor

| Keys | What it does |
|---|---|
| `Ctrl+S` | Save now |
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z / Ctrl+Y` | Redo |
| `Alt+Z` | Wrap or unwrap long lines in code blocks and plain-text files |
| `Ctrl+F` | Find in this page (wherever the keyboard is, not only in the editor) |
| `Ctrl+H` | Find and replace |
| `F3 / Ctrl+G` | Next match (Shift for the previous one) |
| `Ctrl+B / Ctrl+I / Ctrl+E` | Bold / italic / code |
| `Ctrl+Shift+X` | Strike-through |
| `Ctrl+K` | Insert a link |
| `Ctrl+Alt+V` | Insert a database view |
| `Ctrl+Alt+F` | Insert a footnote: a reference after the cursor or selection and the note itself at the end of the page, with the cursor in it. The selection toolbar has the same button (**Insert footnote**) |
| `Ctrl+Alt+M` | Comment: highlights the selected text and adds a comment to it, with the cursor in the comment (with nothing selected, a comment at the cursor). With the cursor in a highlight or comment already, takes it away. See [Highlights and comments](07-comments.md) |
| `Tab / Shift+Tab` | Indent / outdent a list item |
| `Enter` at the start of a list item's text | Leaves an empty item and moves the text down to the next one, at the same level (also in `I.` / `A.` / `1.` lists) |
| `[[` and a name | Suggests pages. When no page has that name, the last choice is **Create page “name”**: the link stays as typed, the page is made under this page and opened |
| `<!--` | Closes itself with ` -->` |
| `Alt+Up / Alt+Down` | Move a list item up / down |
| `Ctrl+Click` | Open the link under the pointer |

## Settings boxes (YAML)

| Keys | What it does |
|---|---|
| `Tab / Shift+Tab` | Indent / outdent the lines selected |
| `Esc, then Tab` | Leave the box instead of indenting |

## View

| Keys | What it does |
|---|---|
| `Ctrl+Shift+E` | Export the page |
| `Ctrl+Shift+L` | Light or dark theme |

**Find bar.** It shows how many matches there are and which one is selected ("3 of 12"); typing jumps to the first match at or after the cursor, and Enter / Shift+Enter step through them. The × or Esc closes it.
