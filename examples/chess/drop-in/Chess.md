# Chess

A game of chess for two players at one screen (or taking turns, if the page is synced between you).

1. Press **New game** to set up the board.
2. The player to move types the move into the **move** attribute above (`e4`, `Nf3`, `exd5`, `O-O`, or by squares: `e2e4`, `e7e8=Q`).
3. Press **Play move**. The board is redrawn, and the move is added to the list.
